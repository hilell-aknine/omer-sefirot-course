# פורטל ספירת העומר · עשר הספירות

פורטל לימוד וידאו עצמאי — 63 שיעורים על ספירת העומר ועשר הספירות, מתוך
פלייליסט יוטיוב. קובץ HTML יחיד, ללא שרת וללא הרשמה.

## תכונות
- 63 שיעורים ב-8 מודולים: 14 שיעורי יסוד + 7 שבועות של ספירת העומר.
- נגן וידאו מוטמע, ניווט שיעור הקודם/הבא, מעקב התקדמות.
- סימון שיעורים שהושלמו + הערות אישיות לכל שיעור (נשמר ב-localStorage).
- חיפוש שיעורים, "קפיצה לשיעור הנוכחי", קישור ישיר (`#v=ID`).
- עיצוב Apple Glass, אפור/לבן/שחור, רספונסיבי, RTL.

## הרצה מקומית
פתיחת `index.html` בכל דפדפן מודרני. אין צורך בהתקנה או build.

## עדכון התוכן
ערוך את המערכים `MOD1` / `OMER` בתוך תגית ה-`<script>` שב-`index.html`.
פורמט שורה: `['YOUTUBE_ID','כותרת','MM:SS']`.

## פריסה
מפורסם ב-GitHub Pages. ראה `CLAUDE.md` לפרטים.
